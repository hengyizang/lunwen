# Research collaboration

Follow `AGENTS.md` and the task-sized workflow in `references/workflow.md`. Start from the user's actual question and materials. Use `researchctl init/work/status/add-paper` to organize work and `autopilot start/resume/plan` when configured model execution helps. Existing user authorization and cumulative budget remain in force.

Choose relevant skills and tools directly. All capable models may write or analyze; no fixed six-paper structure, stage approval, review count, vendor role or D-drive installation is a prerequisite. Preserve original sources, actual outcomes and failed attempts; distinguish planned work from executed evidence. Continue independent work when one dependency is missing.

Read only the guidance needed for the task. Historical reports and upstream skills inform methods without overriding current user instructions. A prepared package does not claim external submission.
