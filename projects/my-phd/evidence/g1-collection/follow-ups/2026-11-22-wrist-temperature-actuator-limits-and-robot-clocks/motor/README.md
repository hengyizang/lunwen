# 独立轴转矩、关节电流与传动间隙的实物对照

四个公开文件来源各有不同的测量链。PTB 和 Durham 的试验提供独立轴转矩参照；张等的空载谐波关节提供驱动电流、前馈回显和编码器；西安电子科技大学的双关节试验提供物理运动轨迹和准静态间隙探测。作者、版本、访问日期、下载地址与校验和收在目录和检索日志内。四份源数据均采用 CC BY 4.0，本目录的派生数值表采用同一许可。[数据目录](sources.csv) · [文献与定位](literature.csv) · [检索与校验和](search.json)

## 谐波关节的驱动电流能说明什么

试验对象是无外加载荷的 eRob70H50I 关节。四个原始压缩包共 105 份 CSV，5,382,824,141 字节，全部按发布者清单核对了 SHA-256 和行数，共 38,064,289 个文本行。并非所有历史记录都用于同一实验。作者另列了 7 个排除文件，其中有一次名义上开启补偿，但回显始终为零；这些文件不在 105 个之内。[原始记录核验](harmonic-raw-verification.csv) · [发布版本](https://zenodo.org/records/23874408)

从 10 个电子凸轮记录中，按发布者定义的条件、位域及半开时间窗重建了 51 个窗口，共 3,990,000 个采样点。对照组 C0 的 1,920,000 个采样点中，前馈回显全部为零；C2-H 的 1,920,000 点中，1,915,528 点有非零回显。按固定或扫频参考轨迹重算，位置 RMSE 与发布表的最大绝对差为 4.9×10⁻¹¹ 度。用总电流减去回显乘 5.4 mA/计数可以重建一个残差，驱动器内部的转矩见证通道缺少可溯源的外部转矩标定。数据不能逐点验证输出轴受力或硬件电流饱和。[按运行复算](harmonic-cam-windows.csv)

## 两种独立轴转矩参照

- **PTB 旋转标定**。在 4 次重复中，台架通道有 13,334,635 条记录，独立传递标准有 1,655,909 条，标称采样率分别为 1,200 与 150 Hz。对作者已对齐的两份文件按极性匹配同步信号的零阈值交越，每边在 ±50 ms 内均须只有一个候选，得到 4,416 对。按首个越阈采样点定义，台架减传递标准的残差从约 −25.0 到 +6.7 ms。数值包含采样分辨率、信号和对齐过程的影响，不能解释为机器人网络单程延迟。[同步沿](ptb-clock-edges.csv) · [数据文件清单](ptb-aligned-files.csv)
- **旋转零位与加载方向**。76 个发布台阶中有 75 个给出起始时刻，第 2 次重复的第一个零载台阶缺时标。对每次重复按各自旋转零位消零后，在 1,100 kN·m 名义增载台阶，台架读数比独立标准高约 44.10–44.43 kN·m。对每个有效台阶，以表列时刻及再等待 20 秒分别起算，按实测转速积分到六整转，给出两种窗与作者公布均值的差。两种窗都是独立复核口径。28 对可匹配的增载/减载台阶另表给出，便于区分旋转零位和回程差。[台阶与时间窗](ptb-calibration-steps.csv) · [回程对照](ptb-reversal.csv) · [PTB 原始数据](https://doi.org/10.7795/720.20190411)
- **Durham 光学转矩**。归档 MD5 与发布页相符，共 13 份文件。两个转速稳态试验和一个中频变载试验有独立 Magtrol 轴转矩对照。将光学时序线性插到参照时刻，仅取重叠区间。1,700 rpm、4 N·m 工况有 46 个可比参照时刻，上升沿法和互相关法的 RMSE 分别为 0.0372 和 0.3681 N·m。1,900 rpm 文件有 3,189 个参照数组槽位，实际只有 55 个有限的时间/转矩对，其中 48 个位于光学时间范围内。四个变工况 CSV 中，仅中频文件提供转矩，急阶跃、低频和高频文件提供转速。各方法可重复使用同一参照时刻。[按时刻配对](optical-clock-matched.csv) · [标定拟合](optical-calibration.csv) · [Durham 归档](https://doi.org/10.15128/r1v979v306n)

## 双关节的回差与接触探测

西安电子科技大学的数据包共 72 个文件，71 项清单 MD5 与文件大小全部匹配。30 个工况各 10 次释放衰减试验，300 条轨迹中的 11 个通道共用 308,329 个时间点。按试次内相邻时间点计，有 211,105 对的两个关节相对角度都未变化；这一统计保留了读数重复，不能据此判断电机停转。9 个偏置位置有正反向探测；6 个位置没有发布归一化增益，派生表保留空值。数据中的同步/异步指两关节激励，同一装置上还包括模拟和推断结果，均未计作跨机器人通信或独立接触力证据。[工况汇总](backlash-condition-comparison.csv) · [试次质量](backlash-trial-quality.csv) · [九点探测](backlash-physical-probes.csv) · [发布版本](https://zenodo.org/records/24046661)

## 复算

从各来源下载原始归档，Durham RAR 使用支持 RAR 的解包工具展开。需要 Python、NumPy、pandas 和 SciPy。四个命令分别生成本目录对应数据表。

```sh
python replay_joint.py output
python replay_ptb.py PTB_download.zip output
python replay_optical.py Durham_extracted_directory output
python replay_backlash.py ResearchData_two-joint_backlash.zip output
```

检索中另查到 2025 年商用风机台架的测试论文。其数据可用性声明明确说明测试数据与处理代码无法公开。论文关联的两个 Zenodo 条目各有一份可读报告，收录在文献目录中。[论文与可用性声明](https://wes.copernicus.org/articles/10/1625/2025/)
