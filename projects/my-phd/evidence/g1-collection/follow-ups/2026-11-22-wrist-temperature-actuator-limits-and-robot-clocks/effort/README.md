# 从执行器请求到实测电流、轴矩和接触力

## 一次可复算的腕部限幅

Zafaranchizadeh Moghaddam 等在 Dynamixel 腕部关节上报告了内部控制量与电流两层输出。作者仓库公开了挑选过的原始时序。主试验目录的 7 条时序与频率、阶跃目录的 10 个时序路径中，有 1 对阶跃文件逐字节相同。按内容排重后共 16 条记录、97,920 行。每行有参考与实测角度、内部控制量、电流映射值、目标电流和实际电流寄存器。未发布的控制程序体由占位文件代替。可核验的仓库版本和许可见数据目录。[论文](https://doi.org/10.3390/s26134212) · [作者仓库固定版本](https://github.com/danialza/hardware-aware-nussbaum-pid/tree/3aa7b699a67e7a32aa29e5681a3eebb272e2017b)

最终配置的 7,200 行可以同时核验**限幅前后**。按论文式 (12) 从每行的自适应参数、Nussbaum 函数值和误差组合值恢复基础命令，再按式 (18) 加入日志中的尾部辅助量和速度前馈量。配置给出 kΔ = 0.1336345470。重建的请求落在 −0.16240446 至 0.10080242 之间。正界 +0.0632 被严格越过 61 次，负界 −0.0632 被严格越过 21 次。经过限幅后的 7,200 行与记录值的最大绝对差为 1.12 × 10⁻¹⁰（内部控制单位）；按每内部单位 210 个原生计数换算，与记录的映射电流最大相差 1.05 × 10⁻⁸ 个计数。[逐通道复算](wrist-headline-reconstruction.csv) · [参数出处](https://github.com/danialza/hardware-aware-nussbaum-pid/blob/3aa7b699a67e7a32aa29e5681a3eebb272e2017b/data/run_commands/final_run_commands.md)

按“严格越界”统计为 82/7,200；按“达到上限绝对值的 99%”统计为 88/7,200，后者复现了公开汇总的 0.0122222。其余可能阈值也能得到相同计数，无法由此唯一还原创作者的阈值。最终运行目标电流绝对值最高 11.947 个计数，实测电流最高 12 个计数，配置的原生电流命令上限为 39 个计数。目标电流字段保有小数，不能当成实际发往总线的整数报文。文中调参目标还用到原生电流接近限值的比例，该比例与内部输出的限幅比例含义不同。独立轴矩未进入这些 CSV。基线原始表没有逐行限幅字段，按其经验最大绝对输出统计有 3,241/7,200 行到达该值。10°、1.5 Hz 的短测有 2,199/2,400 行触及所记录的内部门限，持续约 20 秒。[各运行与分母](wrist-runs.csv)

主调参系列五张表共有 79 行，其中 18 行的评分至少为 1,000,000，79 行的 ok 标记都为 1。其余六张表属于其他调参系列，其中一张有同一试次编号的重复观测；表内同时保留行数、不同编号数和高罚分数。试次编号和配置不足以使调参汇总与每一条原始日志一对一关联。[调参结果](wrist-trial-campaigns.csv)

## 带独立力参照的制动台架

Twente 两滚轮台架用扭矩传感器闭环控制磁滞制动器，用独立测力单元测切向牵引力。4TU 归档内的 139 份实测文本共 3,057,305 行，包含 116 份常规扭矩工况、20 份文件名含 repeat 的记录，以及 3 份不同表面条件下的衰减试验。每份文件的中位采样间隔为 10 ms。扭矩通道采用制动方向的符号，作者的对照使用切向力乘 0.027 m 半径再加有符号的制动扭矩。按整段逐文件求均值、再取文件中位数，三个组分别为 0.308635、0.225737、0.217620 N·m。相应的实测制动力矩与文件名标称设定的平均绝对偏差的组内中位数为 0.026033、0.019839、0.054039 N·m。这些统计包含过渡段；轴承摩擦和动态效应均会影响比较。文件名提供标称值，没有逐点限幅前请求、励磁电流或限幅标记。数据采用 CC BY-NC-ND 4.0，仓库只提供三组独立统计、原始出处和自编核验脚本。[汇总表](roller-test-groups.csv) · [论文](https://doi.org/10.3390/machines11110993) · [4TU 原档](https://doi.org/10.4121/8e5df55a-42f4-45a3-9336-501c38bc4b85.v1)

## 复算

数据版本与许可在 [来源目录](sources.csv)，逐文件 SHA-256 和来源在 [核验回执](source-receipts.csv)。下载 Mendeley 工作簿、Graz 感应电机 ZIP、Zenodo 伺服 CSV 和 4TU 归档后，可使用以下命令。腕部脚本读取固定版本的作者代码库。4TU 脚本也接受 remote 参数从固定文件端点读取到内存。三组结果使用整份原始文件，未复刻作者为个别论文曲线裁切的图窗。Python 3 使用 numpy、openpyxl 及系统 libarchive。

```sh
python analyze_wrist.py hardware-aware-nussbaum-pid output
python analyze_benches.py MotorsData_rev.xlsx Induction_motor.zip Servo_Fuzzy_Controller.csv output
python analyze_tribometer.py experiment.7z output/roller-test-groups.csv
```
