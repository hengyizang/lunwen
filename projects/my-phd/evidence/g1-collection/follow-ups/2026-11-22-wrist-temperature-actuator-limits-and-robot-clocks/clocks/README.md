## 复算

按文件指纹中的 `local_replay_name` 保存两个 ZIP 和三个原名 SQLite 数据库。Python 脚本按整数或 Decimal 读取时间，等距离匹配取较早者，第 95 百分位用最近秩。两方向的测量分别按完全相同且唯一的日志时间配对；未能唯一配对的单端时间戳保留在行数栏中。仪器两侧四个时间戳没有共同的包标识字段。ROA 的脚本还检查 ZIP 的 CRC。HYMN 各定位系统使用相同的地点窗口，地点内只按源时间配对，输出不作时钟校正。原始 SQLite 时间没有时区字段，分析使用同一文件内的时间差。

```sh
python audit_timing.py inputs results
python audit_tables.py smart.pdf publisher.html results
```

第二条命令使用 Poppler 的 `pdftotext`，输入为 5G-SMART D2.3 发布 PDF 与 J-STAGE 的 Nguyen／Chosa 全文网页。论文表中的逐条件均值用于计算对照差，仅回传本批计算的指标。完整来源归属和适用范围见 [文献目录](literature.csv)。另见 [有方向的文献与数据关系](edges.csv) 和 [检索日志](search.md)。
