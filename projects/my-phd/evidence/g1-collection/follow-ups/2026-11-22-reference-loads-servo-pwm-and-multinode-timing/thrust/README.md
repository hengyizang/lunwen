# 水池里的推进指令、实测推力与外力

本目录沿一篇 BlueROV2 闭环控制论文回查其静态推力曲线和动态模型。两个模型项出自不同实测来源。另两组水池实验提供整机系绳张力与光学位置，可以检查台架结论能否沿用到装机后。论文与数据的作者、出处、版本和使用条件列于[文献表](literature.csv)与[数据目录](sources.csv)。

| 读到的文件 | 可复算的结果 | 解释范围 |
|---|---|---|
| Blue Robotics T200、T500 | 两个工作簿共 13 个电压条件、2,613 个电压与脉宽组合。16 V 时，T200 在 1,100 和 1,900 µs 两端分别为 −4.069 和 +5.245 kgf，T500 分别为 −6.10 和 +9.16 kgf。 | 静水系柱试验，每个型号一台。两本工作簿均丢弃启动后 1.5 s 的数据。T200 将低于 300 rpm 的结果归零并取稳定样本均值，T500 将低于 500 rpm 的不稳定结果归零并对过滤后的样本取中位数。零值区宽度包含这种处理的影响。 |
| MathWorks T100/T200 动态试验 | 全部 18 份 CSV、270,018 个时点均有时间、输入脉宽和力。相邻时点间隔 2 ms，仅覆盖 1,600–1,900 µs。12 份文件中共有 12,128 个负力读数。 | 数据覆盖正向指令区间。瞬态中的负读数需结合载荷通道零点、装夹与动态响应解释，不能据此判为发出了反转指令。原始 CSV 没有限幅前请求、电流或闭环状态位。 |
| Edinburgh 受约束 ROV | 178 个归档成员中完整核验 Mot01–18 的 36 个原始/处理文件。18 组共 147,456 个时间点。前进稳态与后退稳态的八根系绳合计 x 向分量均值分别为 −91.96 N 和 +86.20 N。 | 符号沿用发布者的系绳力坐标。这是整机载荷；每个推进器的推力没有独立测量。表 5 提供运动条件，未给逐点 PWM。|
| Khanmeh 等，5 m 缆长工况 | RC 输入和输出各 1,732 行；光学记录 45,625 行，其中原点三坐标完整的有 45,618 行；双轴张力记录 353,160 行。 | 张力表和光学表的中位时间间隔为 0.5、4 ms。原文用文件创建时间移位对齐张力记录，缺少逐包硬件共触发标记；采样间隔无法直接解释为执行延迟。 |
| Ocean Systems Lab 水池轨迹 | 对固定提交中的 39 个不同文件逐一验证 Git blob 和内容摘要，共 183,555 行；八路 PWM 中有 15,108 个通道读数等于 1,100 µs、43,069 个等于 1,900 µs。 | 根目录的演示 CSV 与其中一个文件字节相同，只计一次。各表首列为行索引，未标明显式时间。到端点的次数无法区分手动给定、程序限幅和电机实际饱和；README 将推力和力矩列称为输入量。 |

Edinburgh 的 Mot17 原始文件在 8 行含分离的字母 `d`。复算只在这些行移除额外标记，保留八个载荷通道并校验与处理表的时间一致。原始光学 Z 列存在字符前缀，当前统计未使用该列。处理表在这 8 个时点的方向分量缺失，求和时要求八路全部有效，缺值不会被加作零。

从本目录执行 `python replay.py CACHE_DIR OUTPUT_DIR` 可按摘要恢复两个工作簿、MathWorks 文件包与两份水池归档的指定成员。依赖 numpy、pandas 和 openpyxl。Edinburgh 与 Zenodo 的原包分别约 1.1 GB 和 224 MB，程序仅请求选中成员的字节区间。`python trajectory.py OUTPUT_DIR` 按固定提交从 GitHub 回取 39 份轨迹。元数据、查询和全文检查位置见[检索日志](search.md)，成员校验信息见[文件清单](selected-members.json)。
