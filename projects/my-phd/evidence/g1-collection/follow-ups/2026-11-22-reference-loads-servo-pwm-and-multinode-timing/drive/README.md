# R2 伺服闭环中的输出限幅与力矩观测

10 个已校验的归档覆盖 6 个公开数据来源。按原始 JSON 轨迹计，共 1,912 条轨迹、3,502,113 个采样，其中 2,760,513 个采样标有扭矩使能。另有 489 个 MD300 重采样文件与原始试次一一对应，已从计数中剔除。书目包含 4 篇读过全文的研究和 4 篇书目初筛。

| 执行器及数据 | 从原始文件复算的结果 | 能解释的范围 |
| --- | --- | --- |
| Dynamixel XL330 | 358 条轨迹、224,744 个采样。191,695 个使能采样中，23 个 PWM 读数达到 +1，37 个达到 −1。三个日志均为 `sin_time_square`、Kp 300，合计 7 段。各段绝对角跟踪误差中位数为 1.216–1.584 rad。 | 记录程序读 Present PWM，将有符号计数除以 885 并截断到 [−1,1]。这些是**记录值到达边界**，缺少截断前请求、原始寄存器整数与轴端力矩传感器读数。 |
| Feetech HLS2915 | 数据分支有 4 种臂长/负载配置、64 个位置模式日志。在 63,358 个使能采样中发现 1 个 PWM 回读达到 100%。0.15 m、100 g 的试次在 5.929693 s 的角度跟踪误差为 0.730327 rad，按记录程序标定换算的板载电流为 0.257316 A。 | 字段 `control` 是负的母线电压乘 PWM 比例。全部使能样本可从同一条记录准确重构。记录程序采用特定台架标定的 0.001569 A/count。 |
| MangDang MD-300-150 | 三个输出共 489 个原始试次。各次均记录约 0.99 的 PWM 配置与 1,500 mA 电流配置。556,229 个使能采样中，供电侧电流回读绝对值有两次超过配置值，分别为 1,544、1,521 mA。 | 记录程序根据控制律重建 `duty_cycle`，本批未见实时 PWM 回读字段。两次读数超阈不能证明保护失效或瞬时绕组力矩超限。电压字段是供电设定值。 |
| Unitree J288 | 124 条训练、7 条验证轨迹。按每行反馈增益筛选，13 个文件共有 60,184 个使能采样具有非零前馈力矩且 Kp、Kd 均为 0。逐文件给出请求和回报力矩的平均绝对差。 | 作者说明回报力矩由电流换算。输出编码器提供机械角度，无法独立校验输出力矩。各文件头增益与逐行增益可能不同。 |
| Feetech STS3215、Dynamixel MX/XL320、Waveshare ST3025 | STS3215 两个独立电压版本分别有 100 和 97 条轨迹，全部使能样本的 `load` 范围均为 0 至 0。MX64/106 的 `sin_time_square` 使能样本均出现 −1023、+1023 原始读数。ST3025 的同类波形出现 −1000、+1000。 | STS3215 记录代码给 `load` 赋零。MX 的厂商手册说明 Present Load 源自驱动内部估计。Waveshare 保留原始单位。几种型号的字段不能换成同一力矩尺度。 |

独立机械测量可在 Sun 等的全文中核实。其台架把 FUTEK TRS600-50Nm 装在驱动器和负载之间测相互作用力矩，同时用编码器计算弹簧挠度。论文报告用 8、16 Nm 的转矩指令在 30 s 扫过 0.1–50 Hz，控制图中有电机速度限幅块。数据可用性声明将实验数据定位于论文内，本批保存书目和全文定位。[论文](https://doi.org/10.1115/1.4067431)

## 复算与定位

在当前目录用 Python 3.10 或更高版本运行以下命令。脚本只用标准库，校验整包 SHA-256，原始数据在内存中解析。已有下载时可为每条命令追加 `--cache /path/to/archives`。

```sh
python replay.py --out /tmp/bam-check
python replay_neighbors.py --out /tmp/bam-check
```

- `archive-receipts.csv` 与 `neighbor-receipts.csv` 给出下载 URL、字节数与摘要。镜像的压缩包改版会触发校验错误。
- `servo-waveform-summary.csv` 按型号与波形汇总。使能 MAE 是所有使能采样上目标角与编码器角之差绝对值的平均值，按采样加权。停机和被动摆动不进入该指标。
- `xl330-pwm-boundary-runs.csv` 以归档内路径和从零起的样本序号定位每个连续同号区段。间断、失能或翻转符号即分段。首末时间取自主机记录，不能用作硬件开关周期。
- `neighbor-log-counts.csv`、`neighbor-field-ranges.csv` 和 `neighbor-boundary-observations.csv` 给出贡献者发布的原始/使能计数、逐类通道语义，以及超阈或达到边界的确切文件与时间。HLS 的 `params/` 拟合结果不计为轨迹。MD300 的 `processed/` 不计为独立试次。
- `j288-feedforward.csv` 按文件保留零反馈增益组，在任一增益非零时，`goal_torque` 只构成复合请求的一部分。
- `sources.csv` 记录许可与版本。数据打包文件留在来源方，本目录只含独立编写的统计、复算程序和来源指针。
