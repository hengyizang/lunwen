# 双端无线时间与独立运动参考

Ghent 的移动机器人记录可以按一次 UWB 发射事件找到多个接收节点，并用独立的 Qualisys 光学位置观测运动。Linz 两套装置则保留标签与锚节点各自的六个无线收发时刻。

| 来源与已核验文件 | 实测结果 | 用作控制证据时的限制 |
| --- | --- | --- |
| Ghent TDoA，Random，完整收包与光学 CSV | 22,827 条接收报告，3,322 个标签–超帧组合。3,268 帧有至少两个接收节点，54 帧只有一个。24,723 条光学观测覆盖全部无线记录。最近光学样本的记录时差中位数 3.52 ms，第 95 百分位 9.83 ms | 同一超帧最早和最晚主机记录相距最多 2.944 s。主机写入、排队和时钟处理均可能贡献此差值。光学传感器提供独立空间参考，文件中未验证它与各无线钟的独立校时残差 |
| Ghent ADS-TWR，数据卡两个入口，各核完整诊断和光学 CSV | 分别有 1,757 与 1,623 条测距，均保存 T1 至 T7。光学样本各有 49,296 和 51,093 条，最长相邻采样空档分别为 52.54 s、35.55 s | 论文 §III 描述过相隔六个月的两次实验。两份指定文件的无线时间均为 2023-07-10，起点仅差 678.015 s。它们与文中两次实验的映射待证。进入光学首尾区间的无线记录中，分别有 201 与 142 条距离最近光学样本超过 50 ms |
| Linz 静态弱非视距转台，完整 24 个训练与 12 个测试文件 | 从 1,289,910 行逐包诊断识别出 429,970 次三包交换。每组内六个双端时刻完全重复，四个端内时间差与源表均逐项一致。134 次交换有源时间值达到或超过 2 的 40 次方 | 三行共有一组时钟，应按交换键合并。转台角度和参考距离代表试验设置，每次交换对应的独立机械动作时刻仍缺失 |
| Linz 动态模型铁路，三个运动 CSV 和参考轨道 | 三条记录共 101,871 次测距，每条都有八个锚节点参与。六个无线时刻保留标签与锚节点的收发顺序，29 次至少有一个端内差值跨过 40 位计数回绕 | 由激光校准的轨道参考文件只有 400 个索引平面坐标。每个点缺少独立时间，不能逐包恢复真实列车速度或位置 |

Ghent 卡片将 Random 描述为 8 个锚、3,268 个样本。完整文件中有 16 个接收标识，3,268 正好等于多接收节点超帧数。论文的处理选择可改变进入评估的锚节点和样本，完整表没有给出与卡片上 8 个锚的一一映射。同一标签、超帧、锚的键没有重复，原文件顺序中主机 Logtime 出现 10,189 次回退。最近光学样本按公开 Logtime 匹配，这只表示记录时间接近。

linz-clock-summary.csv 按文件和锚列出时刻一致性、端内间隔比以及发布测距与参考距离的差。两端间隔比为“标签第一次到末次发送的间隔 ÷ 锚第一次到末次接收的间隔”，减一后换算为 ppm。它表达本次交换两端所见时长的差，受端点、射频误差与运动影响。107 个文件–锚组合中，35 个文件有三个锚，另一训练文件只有两个。linz-rail-exchanges.csv 单列动态铁路的三次采集和各节点，单次采集、单个节点内协议码和序号组合均唯一。

ghent-file-manifest.csv 指向六个文件的原始地址并记录 SHA-256。两个 Ghent 方向同属一份目录，分别有 TDoA 接收流与 ADS-TWR 数据。document-versions.csv 给出实际阅读的 12 份 PDF 的版本和摘要值。sources.csv 与 literature.csv 逐条记录来源、证据级别和使用条件。edges.csv 区分论文引用和数据卡推荐文献。

复算需要 Python 3 与 NumPy。Linz 转台完整采集共 1,334,773,466 字节，程序一次在内存中处理一个文件，对照固定提交的 Git blob ID 后静态读取数值缓冲区。发布材料只有自写代码、书目与汇总值。

    python ghent_motion.py --output results
    python linz_clocks.py --output results
    python linz_rail.py --output results
