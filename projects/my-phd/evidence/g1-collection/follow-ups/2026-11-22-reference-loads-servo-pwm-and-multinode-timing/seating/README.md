# 装配腕力、接头压合与锁止声

这批材料补充了三种可以相互区分的观测。腕部传感器能记录装配过程中的载荷，压力膜能记录压紧后的空间分布，音频配合视频能识别接头的一、二级锁止事件。本批没有发现用同一时间基准同步记录腕部六轴力、独立载荷和最终机电锁止的试次。[来源目录](sources.csv) · [文献与证据位置](literature.csv) · [引文和资料关联](edges.csv)

## 时间与证据的边界

HARTU 原始腕力话题各带独立时间戳。所抽各路时间戳严格递增，中位采样间隔约 16.4 ms，单个间隔可达 0.957 s。示例 PCL 分步操作每侧的原始腕力有 687 行，处理后的 `cart_wrench` 有 651 行，`cart_pos` 有 5,061 行。`cart_wrench` 和原始传感器话题不得当作两套独立测量。本文只分别汇总各流。中央目录列出 34 个 `demo.hdf5`，其中 33 个所在演示目录下可见 `.db3`。[逐通道检查](demo-channels.csv) · [完整目录与实读标记](hartu-members.csv)

Bricher 与 Müller 的产线论文记录两类接头、每类两级锁止，同时视频用于人工判读声学候选峰和相似噪声。Rouwhorst 的剃须刀卡扣试验提供了反例：拆去一个钩后，声音包络仍可能近似完整件，更换工件也会改变模型判断。库内单独登记了两项研究，避免将声响自动视为完整机械或电气连接。[2020 年连接器试验](https://europepmc.org/articles/PMC7256605) · [2023 年剃须刀卡扣试验](https://fse.studenttheses.ub.rug.nl/31249/1/mME_2023_RouwhorstE.pdf)

## 核对与重算

五个数据目录均标注 CC BY 4.0。各表由目录所署名的原始资料重新计算，文件名、版本和摘要见检索日志，许可链接列于来源目录。代码需要 Python、NumPy、h5py 与 openpyxl。运行 `python audit.py --out /tmp/check` 可从固定版本重算装配、标定、压合及拉伸表；`--dataset robot` 等选项可指定来源。运行 `python audit_clicks.py --out /tmp/check/click-features.csv` 可单独核对线束声音特征。[检索日志](search.md) · [触觉标定](patch-tests.csv) · [压合统计](pressing.csv) · [锁止声特征](click-features.csv) · [接头强度](rivet-tests.csv)
