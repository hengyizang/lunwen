# 指令、传感与实际动作的计时证据

本批收录 13 项新增书目，其中 10 项已读全文，3 项为顺着引文取得的书目记录。另有 1 项历史初筛文献升级。两处 OSF 验证库有原始控制器或标记文件，另有一段固定版本的同镜头视频。三篇机械手论文和两篇守门机器人论文分别来自同一研究系列，跨篇合计时应保留这种依赖关系。文章、控制器原始日志和视频均保存在原发布处。目录内保存版本标识、独立计算的数值和检索记录。

## 外部参照和主要结果

| 实验 | 起点、终点与时基 | 观察结果与适用范围 |
| --- | --- | --- |
| KR5 sixx、UR10 | 控制指令、独立 8 kHz 末端陀螺仪、控制器回报，比较三条速度曲线的极值 | 作者的平均动作延迟分别约为 90 ms 和 20 ms，由各自控制周期换算。设备姿态、运动轴和速度估计都会影响结果。关联的早期 UR10 报告只够检查反馈包。 |
| UR3 与步进电机带动的手模 | 两个相对同步精度标称 <1 ms 的 200 Hz Opal 陀螺仪，同测手模和机械臂 | 作者报告完整信号相关滞后 110 ms。图 4 仅展示 75–80 s，本批读图对应 147.3–154.6 ms；可见波形、覆盖窗口和原始记录不同。UDP 时钟差与机器人内部动力学无法从总量拆分。 |
| 事件视觉守门机械臂 | 闪烁 LED、控制器 GPIO、电源电压下降、视觉跟踪位置 | 新版论文报告到 GPIO 中位 2.2 ms，到电机通电 5–15 ms；一次拦球动作约 80 ms 到位。2007 会议报告的 2.8 ms 截止于控制器引脚。 |
| 5G 触觉双向远操作 | 480 Hz 外部相机观察 Falcon 的反向加速度，实物时钟与屏幕同框比较，另测用户动作至监视器 | 无追加网络延迟时，触觉代理均值 6.25 ms、光学链路均值 52.52 ms、动作至显示均值 57.49 ms。原文另测了 5G RTT。图 6 三条 CDF 的 P95 可由图形取出，详见下文。 |
| 人形机器人远操作 | 同一相机记录反复摆动的人手与机器人手。项目示范有彩色叠加，标注为半速 | 原文有线 MoCap 54±4 ms、无线 VR 64±8 ms。本批复查公开示范得到 3–4 个播放帧，对应约 50.1–66.7 ms。有连贯同镜头，但原始仪器轨迹、曝光和编辑过程未公开。 |

## 触觉输出文件复算

**Perceptual Crossing Device，OSF 9ecxu。** 四个下载包中有 44 个有意义的 CSV 或标记文件条目。按解压成员 SHA-256 发现单独发布的 `MotorExtraDataset.zip` 全部 7 项都已收入 `MotorDataset.zip`。独立成员含有 32 条约 60 秒的控制器采集（1,053,083 行）和 5 条 BrainVision 响应标记流（4,254 项）。各自时钟内的时间严格递增。图 11–14 说明按钮电压和声学探头如何给硬件动作打标。探头测到振动声，未直接测得接触力或人的触觉感知时点。[论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11164400/) · [公开验证库](https://osf.io/9ecxu/files/osfstorage)

| 通道，各选 6 个试次 | 作者有效个数 / 均值 ms | 本批按最近边沿配对个数 / 均值 ms | 本批中位 / P95 ms |
| --- | --- | --- | --- |
| 实体按钮至 Pi 日志 | 704 / 1.9 | 719 / 1.877 | 1.851 / 3.105 |
| 软件输出至声音 | 862 / 3.2 | 885 / 3.142 | 3.189 / 4.885 |
| 软件输出至电机振动 | 112 / 16.2 | 121 / 17.530 | 14.376 / 40.912 |

复算使用逐次重置的 Pi 秒表。将按钮组的 R1、声音组和指定电机组的 R5 依次作为对应试次起点，在 R4 内找离软件上升沿最近的检测，并限制一对一和绝对偏差小于 100 ms。按钮取记录时间减物理时间，声音和振动取物理时间减软件时间。按钮使用文件名给出的 5 kHz，后两组用 1 kHz 作对齐假设，60 秒试次长度及匹配情况提供一致性检查。保留 3、8、1 个小幅负差以展示时钟对齐与误配的不确定性；这些负差没有物理负延迟的含义。其余电机记录保留在目录核查表。原文没有披露逐事件筛选掩码，本批另列样本数。

**Enactive Torch，OSF vrsya。** 在 5 个真实标记文件中，针对同一接收记录器内的 `Start` 或 `Rest` 与 `Box`，按“检测前的最后一个命令，命令后的第一个声学事件”一对一配对。另列全体正差和至多 100 个采样步的结果，100 取自随附 `restBox.m`。脚本与论文将一个采样步作为 1 ms；公开标记目录没有用于独立核实采样率的配套 .vhdr。内置电机，两种起点得到完全不同的分布。传感输入组 143 对、均值 22.483、P95 47.8 个采样步。计算机命令组的第二次内置电机记录 121 对、均值 10.421、P95 28 个采样步。两组均与论文的样本数和四舍五入均值一致。相同筛选作用于另一条计算机内置电机记录时，均值为 24.767 个采样步。外置传感组保留 185 对、均值 12.784；按作者另一脚本末尾剔除一对的做法作敏感性检查后得 184 对、12.810，与原文对应。外置计算机组同样处理为 149 对、8.517，原文为 149 对、8.50。代码不把这项差异四舍五入成一致，也不把不同配对规则合并。[论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13226956/) · [OSF 项目](https://osf.io/vrsya/overview)

## 图形和示范视频

- `haptic-loop-cdf.csv` 从 Kroep 等人图 6 的三条矢量曲线取数。模型更新、机器人识别白板变化、本地预测力反馈的 P95 依次为 8.110、5.628、6.250 ms。每条曲线含 100 个等概率绘图顶点。前两条曲线顶点均值 6.780 和 4.664 ms，与正文报告的 7.36 和 5.12 ms 有差异。原始事件文件与绘图程序均未取到，两套数值分别保留。[论文，图 6](https://pure.tudelft.nl/ws/portalfiles/portal/246803831/3716550.3722020.pdf)
- `graph-video-lags.csv` 用 Duarte 等人图 4 的实测光栅图、两个已标时间刻度和两条颜色曲线，逐列读中位高度。计算三组颜色距离、三组窗口的正负滞后 Pearson 相关；遮挡列当作缺失，固定输入区间以比较各滞后。它给出对论文局部图的独立读数，无法复原作者所用整段 200 Hz 测量。[论文，图 4](https://arxiv.org/abs/2407.11560v1)
- 同表也用 ExtremControl 作者项目的固定提交读取 `Flow_wave.mp4`。共 359 个 30000/1001 Hz 播放帧。选帧号 100–245 的叠加稳定区，画面缩放至 760×428，从人工预选人手、机器人手矩形读取对应着色像素的垂直中位坐标。最低支持为 40 个像素。搜索 ±10 帧、共 3 种颜色门限，按图中 0.5× 标注换算物理时间。估计代表反复动作的最佳对齐；演示片离散化、阈值变化能影响一个帧。[作者说明](https://extremcontrol.github.io/#latency)

## 复算和目录

`file-manifest.csv` 有每个实读输入的版本、大小、SHA-256 与获取地址。`literature.csv` 是新增论文，`literature-upgrades.csv` 专列历史条目升级，`sources.csv` 是两处数据项目与一段视频，`edges.csv` 记录作者实际引用或链接。发表图的来源以其论文身份计数。

使用 Python 3.10+ 和 NumPy 运行 `python measure.py`、`python pcd_pairing.py`。图形和视频另需 PyMuPDF、Pillow、FFmpeg 与 FFprobe，运行 `python measure_figures.py`。可用 `--cache DIR` 指向按清单文件名存放的本地源文件，`--output DIR` 指定结果目录。默认拉取公开版本并逐一校验哈希。未将原始文件打包入库。
