# G1 检索与证据

对项目状态提交 `634b9fb8bcb59ae08644e28368e44cf25108b52f` 进行全历史排重后，`literature.csv` 收录 20 项本轮核验过全文的新增来源与 2 项仅筛到书目信息的新增来源。其中两篇 LTO-3 相关论文和一篇学位论文合并标记研究家族。IFAC 报告与学位论文使用同一款磁带伺服实验，CDC 论文只报告数值仿真。两项既有 iCub 全文锚点单列在 `context-previous-fulltext.csv`，不计新增。`citation-edges.csv` 中 9 项引文从本轮新增全文核验，另有 1 项 iCub 的既有版本关系。

## 可复算的表内对照

- `environment-contrasts.csv` 含 16 个同一传感器、相同加载状态和观测时长下的输出差值，单位 mV/V。以条件循环的初始状态为基准，对照升温或升湿后的状态，以及恢复原设定后的状态。3 分钟与 30 分钟共享同一次试验过程，不能作为独立样本。记录覆盖 3 个型号/序列号组合，T34-R40#607101 同时参与两类条件循环。原论文表 1–2 另列测量不确定度。
- `loading-sequence-contrasts.csv` 含 7 个仪器与量程组合在满量程加载后 30 至 300 秒内的蠕变对照。两列分别给出直接加载与部分分步、完整分步加载的差值。5 组的直接加载值严格大于两个分步加载值。不同容量与结构组合的结果不宜直接汇成一个平均修正系数。
- 两表均是根据论文已发表数值自行计算的配对差值。原文作者未在上述来源中提供这些试验的独立下载时序。仓库保留自算结果、出处和方法，两个标定标准上的量值不能直接作为机器人腕部力矩偏置。

下载 `literature.csv` 中 `torcreep` 与 `load2010` 对应的两个原始公开 PDF，配有 Poppler 的环境可以从任意目录执行下式。脚本先核验源文件 SHA-256，验证行数和唯一键，按 Decimal 十进制定点计算，再写出两张表。旧版 2017 PDF 的交叉引用索引可能触发 Poppler 的重建提示，提取数值另已逐行对照表格。

```sh
python3 derive_printed_calibrations.py IMEKO-TC3-2017-022.pdf IMEKO-TC3-2010-042.pdf output
```

`search-log.json` 保存实际检索 URL、执行时间、返回前八项，以及公开源文件获取路径、大小、散列或失败原因。可检索的文献与独立开放原始数据使用不同的证据标签。论文的可访问性和版权信息按行标注。新旧工作判定见 `history-screen.json`。
