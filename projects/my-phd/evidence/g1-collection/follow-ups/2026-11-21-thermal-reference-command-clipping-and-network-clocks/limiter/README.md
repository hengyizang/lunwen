# 闭环驱动的限幅、转矩测量与可辨识边界

## 实测直流电机的位置环

Lizarraga 等人的三批 ESP32–L298N 试验共有 2,942 个不同的原始 MAT 文件、355,982 个采样行。对每个文件按其固定版本的 Git blob 校验内容。2,924 个试验至少触及一次控制器输出边界，共 47,157 行，其中正边界 43,535 行，负边界 3,622 行。按固件、确认回执中的增益及编码器网格重算时，355,982 个整型输出全部匹配。47,094 行的取整前请求严格越界；另有 63 行仅因取整而达到边界。该重算值来自软件回放。最长连续触边为 101 个样本。[论文](https://doi.org/10.3390/eng7080397) · [固件与数据](https://github.com/lizarragaxyz/Closed-Loop-Learning-Based-PID-Tuning-for-DC-Motor-Actuators/tree/8c74893a15c2c110e880d41eabd0d648bd2dcc93)

固件先算出有界整数 `u`，再用位置死区决定是否停止驱动，串口仍发送原来的整数。85,173 行落在死区，内含 18,426 行非零 `u`。触边的样本均在死区外。用日志拟合输入时需计入死区；电机端电流、电压和独立转矩均未由这些通道给出。日志时间是采样序号乘标称周期，不能据此估计调度抖动。仓库对部分代包含重复运行有明确说明。这里按不同文件统计，未把文件直接指认为论文某张图的试验。[运行循环](https://github.com/lizarragaxyz/Closed-Loop-Learning-Based-PID-Tuning-for-DC-Motor-Actuators/blob/8c74893a15c2c110e880d41eabd0d648bd2dcc93/firmware/TunePID_L298N/TunePID_L298N.ino) · [采集说明](https://github.com/lizarragaxyz/Closed-Loop-Learning-Based-PID-Tuning-for-DC-Motor-Actuators/blob/8c74893a15c2c110e880d41eabd0d648bd2dcc93/data/README.md)

## 具有独立轴转矩测量的发电机对照

Tominaga 等人的完整三相永磁同步发电机子集含 225 个通过 Git blob 校验的 MAT 文件、1,206,926,234 字节和 13,500,225 行数据。9 个转速/转矩组合各 25 个记录，每个记录 3 秒，含首尾共 60,001 个时间点。数据提供三相电气测量、电流参考、由相电流变换的 dq 电流、相电压参考、占空比、外部 T22 轴转矩传感器的读数和另行计算的电磁转矩。40,500,675 个相占空比均位于 0.08320777 至 0.91014535 之间。各相按 `0.5 + Vphase_ref / Vdc` 重算与记录差的最大绝对值约为 4.274×10⁻⁸。可用这些运行量化闭环跟踪残差；在这些占空比上没有 0 或 1 处的削顶。[数据版本](https://doi.org/10.5281/zenodo.15741561) · [论文与通道说明](https://doi.org/10.1016/j.dib.2025.112040)

各记录内 q 轴电流跟踪 RMSE 为 0.07076–0.16003 A；按三相合并计算的实测相电压与参考相电压 RMSE 为 8.1839–9.9498 V。轴转矩每个记录只有 3–11 个不同数值，读取时间网格与传感器独立更新率应分开处理。`Spd` 均值除以由文件名换算的机械转速为 2.00133–2.01271；电磁转矩均值除以反号后的实测轴转矩均值为 1.73281–2.13251。使用前需核对各自测量和定义。健康工况亦包含置高的继电器命令，`Package_loss` 是收到有效 CAN 报文后复位的积分量。这些通道不直接提供饱和事件标签。[固定版本的 MAT 文件目录](https://github.com/InnovaPower/MitDev-Eletrica/tree/e02fba475cf82b375412a7382143dc29da5241ef/PMSG-3phase-Dataset)

## 保护限幅与实测轴转矩在同一台架上的证据

Meghawer 等人按当前油门对应转矩上限的 85% 限制负载命令，用标定曲线计算每步削减转矩，另设轴上转矩传感器。表 3 的 8 次试验中，平均限幅激活时间占 8.38%（95% CI 7.50–9.27%），削减的指令冲量为 0.49%（0.03–0.95%）。实测转矩对限幅后命令的 RMSE 为 0.700 N·m（0.511–0.889 N·m）。暖机 7 次是这 8 次运行的子集。页面声明原始全速文件在本地留存，计算结果及分析脚本可以向通讯作者合理申请。公开证据为表 3 的 7 个指标，逐样本时序的可下载性仍是缺口。[论文、表 3 与数据可用性声明](https://doi.org/10.3390/s26196320)

`literature.csv` 记录论文和证据定位，`citation-edges.csv` 记录追查的引文。两个原始数据来源的归属、版本、许可和清洗范围见 `data-sources.json`，已发表表格的归属和转换见 `published-table-source.json`。按 `derive_lizarraga.py` 的用法向其提供解包目录、固定提交的递归 tree API JSON 和输出目录；`derive_pmsg.py 输出目录` 从固定提交的公开文件重新计算。运行两个脚本均需 NumPy 和 SciPy。`search-log.json` 记录本批查询与排除理由。
