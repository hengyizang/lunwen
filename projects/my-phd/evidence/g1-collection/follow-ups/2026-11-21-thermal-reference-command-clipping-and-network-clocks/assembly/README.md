# 实物连接器的接触、锁止和几何到位

本目录收录 7 篇作品，其中 6 篇核读全文，1 篇依据机构摘要初筛。数据目录有 6 个来源，包含作者实测容差汇总、论文矢量图、两份论文汇总表、一个代码及权重包，以及一个真机光学测量数据包。多篇文献可复用同一来源；这些数字分别按作品和来源计数。

- Yumbla 等用 LED 连通板确认针脚导通，腕部六轴传感器同时测量夹具 Z 方向的力。作者网站给出 70 行、15 类硬件的方向容差。网站列名为 Z/X，论文 §2.3 按试验台 x/y 描述位移。汇总保留网站列名。Z 中位数 0.95 mm，X 中位数 0.85 mm。原表 62 个独立料号字符串，8 个各出现两次，3 个跨 C14/C15。行号是复查单行的入口。现有表只支持比较容差，缺少同步电信号和力时序。[作者数据](https://fryumbla.github.io/Manipulation/tolerance/) · [论文](https://doi.org/10.1007/s11370-019-00307-5)
- Bargsten 与 Kirchner 的插拔实验包含一次完整成功循环，第二次部分插入遇到错位、卡住、滑脱后停止。图 14 和图 15 的关节 18 扭矩是同一段物理操作。两图显示不同的频域处理结果。图 16 来自单独的腕部力传感器，给出三维力的模长。按矢量图顶点读取，0–60 s 的最大模长约为 127 N，60 s 到图末约为 81 N，论文把错位标在约 67 s。在这次作业中，若以整段最大峰值定位错位，会选到更早的时刻。没有可由这组三图恢复的逐帧六维测量、空载真值或针脚通断信号。[原文 §3.2 及图 14–16](https://www.dfki.de/fileadmin/user_upload/import/13610_s11370-023-00481-7-1.pdf)
- Kernbach 等用放宽的末端位置阈值计入成功，作者明确允许在电接触发生前结束测试。表 IV 四款连接器各测 90 次，成功率 90.0%–94.4%。Kienle 等记录的是探测路径是否能在规定力限内走完，见表 III 优化后 88%–98%。两项均与逻辑通断不同。Caporali 等加入回拉检测，30 个 Molex 总成中有 1 个回拉被判成功但导线实际未锁牢。Molex 的 231 次插针和 30 次总成测试是不同分母。[Kernbach](https://arxiv.org/abs/2602.22100v1) · [Kienle](https://arxiv.org/abs/2503.09409v2) · [Caporali](https://doi.org/10.1109/TMECH.2026.3654272)
- IntelliMan 的 ZIP 中共有 9 个 Python 文件、4 个权重和 1 份说明，经全包 CRC 验证。触觉推断脚本要求外部提供推、拉两份文本。档案目录逐文件记下大小及 CRC，可据此核对现有公开材料是否适合重做实验。[Bologna v0](https://amsacta.unibo.it/id/eprint/8779/)
- NIST 的无线力反馈实验给出了独立运动观测。UR3 按腕部力反馈接触弹簧，OptiTrack 从外部测量竖直位置。26 个 CSV 有 19,900 条循环记录，提供接触位置和持续时间，无逐帧光学轨迹、腕力或逐包时序。34 个非正总时长和 12 个为零的接触位置按列标记，8 次循环号未递增。两个元数据文件名与 ZIP 清单不一致，表中同时保留两者及匹配依据。部分末端等待或停留极长，直接保留。仅对总时长为正、接触位置为负的各自子集分别计算中位数，两个有效分母逐行列出。[NIST 数据与来源](https://doi.org/10.18434/M32077) · [实验论文](https://doi.org/10.1109/ISIE.2019.8781418)

## 复算

凭 `source-catalog.csv` 的 `asset_url` 下载输入。Bargsten 的脚本锚定 DFKI 作者版，其他排版版本的 PDF 校验和可能不同。DFKI 若对默认脚本客户端返回 403，普通浏览器读取同一 URL 可取得已登记的文件。第一次命令可使用 `--rendered-table` 比较在线渲染页面与冻结版本。使用 Python 3.12.14、PyMuPDF 1.26.6、NumPy 2.3.5、lxml 6.1.1。

```sh
python derive_assembly.py --tolerances tolerance.md --paper bargsten.pdf --intelliman INTELLIMAN.zip --output output
python derive_nist.py Force_Seeking_Dataset_V2.zip output
```

每个图以各自的坐标格线拟合时间轴和值轴。对唯一矢量线段端点按一秒窗口取最小和最大值，最后一窗仅覆盖图中所画的部分。图 14、15 在各自的 20–21、57–58、58–59 s 窗内没有路径顶点，用空字段表示；某段线可横跨这些窗口。极值精度受绘图和坐标标注约束。输出小数用于复算比对，传感器采样精度须查原仪器档案。图中两份相同关节通道仅作提取一致性复核。另两份论文汇总表和 Caporali 结果表采用人工逐项核对，对照位置记录在 `literature.csv`。
