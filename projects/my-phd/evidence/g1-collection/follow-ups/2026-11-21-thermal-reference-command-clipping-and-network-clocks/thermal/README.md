# R1 温度与物理力测量

汉堡的两份机器人触觉记录可以检验指端热敏通道、接触载荷和时间之间的关系。上一批 36 小时腕部 ATI 漂移记录缺少该腕部传感器自身温度。这里能取得的温度分别来自 BioTac 指端、单轴载荷传感器本体和实验环境。

| 物理记录 | 可核验结果 | 判断边界 |
|---|---|---|
| TAMS / Ruppel 两份原始 ROS bag | 515,257 个触觉时刻、618,814 条独立六轴扳手消息，495,084 个触觉时刻在 5 ms 内找到扳手消息。外力范数 ≤0.1 N 时，stick 记录首、末各三分之一的 TDC 中位数从 1919 到 2021，flat 从 1854 到 1992。| 温度为 BioTac 的 TDC 原始计数。参考扳手来自固定于接触物体的独立 ATI。时间、接触分布和温度同时变化，单凭这些差异无法确定传感器偏置的原因。|
| Mao 等 Fig. 3j 实验工作簿 | 同一指端六轴传感器在 25、30、35、40、45 °C 下各测五次。两端 Fz 均值相差 −1.22095 mN，端点割线为 −0.0610475 mN/°C。| 使用作者给出的 Fz 均值和标准差。此页缺少逐次时间戳、独立载荷读数和力矩分量。|
| Gallo 等 Fig. A.2 载荷台 | 同一十秒图窗内有载荷传感器本体温度和实测轴向推力。按 1 秒读取，绘制温度线的中位数约 24.3 °C，绘制推力线覆盖约 9.37–9.49 N。| 读图分辨率只适于描述平稳时段。推力来自该单轴传感器，伴随数据包的推力已按 30 秒取均值。|
| Paulsen 与 Weiler 恒载对照 | 三枚传感器各放置固定质量，图中空气温度约 5.5–21.2 °C，三个重量变化的绘图范围分别约 0–4、0–2 和 0–3 g。| 图例中的棕线 LC1 达 4 g；补充材料正文称 LC3 达 4 g。质量与通道的具体映射未知。|

Zai El Amri 与 Navarro-Guerrero 复用汉堡实验，在其 Network B 实验中，用实测温度时归一化 MAE 为 9.6%，用最佳固定温度时为 22.8%。Guggenheim 等对两类浇注材料的零载元件实施热升降，随后对六轴整机和 ATI Gamma 的比较保持了恒温。两篇文献都有可定位的全文证据。

## 文件与复算

- sources.json 存有来源网址、稳定标识符、文件字节数、SHA-256、作者、版本、许可与局限。采用 CC BY 4.0 的表格和图形衍生数据沿用该许可。改动包括字段规范化、图线读数、时序配对和分组汇总。原作者见各条来源。
- literature.csv 含六篇研究，Mao 为已收论文的源文件补录。search.json 记录了引文追查、排重与未证实的线索。
- biotac-match.csv 使用两个主题的 ROS 消息头整数纳秒时刻，在参考流中选绝对时间差最小的一条，等距取较早者，剔除超出参考范围或时间差超过 5 ms 的帧。不同触觉时刻可配到同一扳手事件，表中另列唯一扳手数。时间差仅表示记录时标的一致程度。
- biotac-reference-bands.csv 按外部三维力范数和记录时段分组。TDC 和 PDC 取第一个触觉槽位，力和矩范数分别用参考传感器坐标中的三个分量计算。阈值 ≤0.1 N 和 >1 N 用于分组，真实接触状态仍需独立标注。每段连续采样内部相关。
- mao-figure-3j.csv 保留源工作簿五行。gallo-figure-a2-bins.csv 对固定像素坐标系下每个时间窗的绘图线条取色，温度取线像素中位数，推力取上下包络。像素宽度影响末位。paulsen-figure-s1.csv 根据原 PDF 中的矢量折线和坐标轴刻度提取绘图范围，路径顶点数与观测次数含义不同。作者报告每 10 分钟采样、实验持续一周，负载图线本身可见约 120 小时。

按 sources.json 下载相应文件并验算 SHA-256，再执行下面两条命令。已用 Python、NumPy 2.3.5、PyMuPDF 1.26.6 及 Pillow 13.0.0 复算本目录数值表。

~~~sh
python rebuild_biotac.py hamburg.tar output
python rebuild_figures.py mao.xlsx hsup.pdf acoustic2 output
~~~
