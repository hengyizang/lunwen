两个公开清单分别列出 13、9 个文件。22 次文件核验均匹配仓储声明的长度和 MD5。实读文件共 21 个不同 SHA-256，含 19 个数值文件和 2 个 PDF。唯一相同文件为 `T7_100.txt`（1,402,688 字节，MD5 `e749af1e5f49fce2c6c335c82c934e60`），保留 v.1.0 调压器电压的通道含义。v.2.0 独有 8 个文件、73,011,553 字节；v.1.0 另 12 个文件未出现在 v.2.0 的公开清单中。两份原始 PDF 均已读取，表 1 给出 v.1.0 的采样率、轨迹和长度，表 2 给出 v.2.0 的轨迹及长度。[表 1](https://zenodo.org/records/4556924/files/Table_1.pdf) · [表 2](https://zenodo.org/records/5514351/files/Table_2.pdf)

v.1.0 的 12 个电压文件共 3,878,500 个样本，其标称 0–10 V 边界的复核见 `belgrade-regulator-voltage.csv`。v.2.0 的七个新文本记录正常运行期间本地控制器 LC1 从 LC2 接收到的值。各 400,000 行、每行 1 个有限数，共 2,800,000 个样本。7 个文件中恰好等于 0.2 的有 523,649 行，恰好等于 1.0 的有 2,049,093 行。T3_v2 在从 0 起算的索引 279216、356894 处还记录了 1.00002003、1.00000799，其他文件的最大值均为 1.0。v.2.0 记录描述给出每条约 200 分钟，表 2 未列逐样本时戳或采样率。单列接收数据未附量纲、发送端副本、模拟输出或实测缸内压力。端点出现次数本身无法确定限幅位置或通信时延；相同的轨迹标签也不足以把两个版本按行同步。[v.1.0 通道定义](https://zenodo.org/records/4556924) · [v.2.0 通道定义](https://zenodo.org/records/5514351)

`belgrade-version-audit.csv` 按版本、文件记录两个公开版本的文件哈希、字节数和统计量，保留两个受限版本的独立状态行。计数建立在解析原始文件后的原生数值相等比较上。可以用 NumPy 和 Python 直接从固定 DOI 对应的公开记录复核。脚本仅保存文件级派生统计，使用 `--cache` 时将原始文件另存于指定目录。

```sh
python audit_belgrade_versions.py belgrade-version-audit.csv --cache replay/belgrade-versions
```
