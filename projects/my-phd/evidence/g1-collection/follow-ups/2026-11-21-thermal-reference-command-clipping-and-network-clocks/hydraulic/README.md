# 液压试验台、气动执行器与双轴同步

`sources.json` 为 4 个数据版本保留作者、来源、许可、文件校验和、审阅范围及测量局限。下表列出的三个 Zenodo 固定版本均按源站公布的大小与 MD5 核验全部归档文件。Dresden OPARA 记录按 HTTP 字节范围读取测试集和说明，对 558 个 ZIP 成员逐一解压并验证 CRC，其中 554 个位于测试分区。本次未读取训练与验证分区，清单保留源站整包 MD5 供日后全包核验。

| 数据 | 本轮可复用结果 | 解释边界 |
| --- | --- | --- |
| Dresden 三分量液压台架 OPARA-151 | 18 个激励条件、每个两次实测、三个轴，共 54 行。给出力和位移的重复测量差异及频响模型误差。 | 30 个服务载荷轴行缺源驱动波形。27 个轴行的前向预测与实测长度不同，逐点误差留空。驱动力设定不等于伺服阀位。 |
| Belgrade 集中控制电气气动台架 4556924 | 12 个调压器电压文件，共 3,878,500 个采样值。其中 242,080 个高于标称 10 V，170 个低于 0 V。 | 单路电压无法区分标定偏差、轨端超量和下游实际限幅，无法据此判断积分饱和。 |
| EPFL 软体气动执行器 3627901 | 93 个试验 CSV，涵盖拉力、端部加载和三点弯曲。排除 63 行满足预先记录阈值的起始异常值，按模块汇总力向量范数。 | 90 个 CSV 在 MAT 文件中存在完全相同数组。不同夹持边界下的反力需要分别解释。六个应变测量通道来自三个二维测力模块。 |
| Duke 分布式双轴定位台 6399688 | 30 次双轴重复的 60 条实测轨迹各 61,000 点。X、Y 参考文件实有 64,759 和 65,288 点，保留公共前缀误差与未配对尾长。 | 仓储说明把所有信号写为 61,000 点。现有编码器轨迹不包含 PTP 报文时间，按样本索引配对不能反推出单向时延或两时钟漂移。 |

可复算步骤写在 `fetch_dresden.py`、`derive_dresden.py` 和 `derive_pneumatic.py` 的文档字符串中。数据输出单位由各列名指明，原单位尚未确认的列保留 `native` 标记。

`literature.csv` 包含三类记录，分别为全文证据、全文勘误与书目初筛。两篇 ETFA 论文与公共技术报告均给出原文所在图表，并标记时序测量、仿真和物理实验的区别。引文方向及核验位置见 `citation-edges.csv`，检索回执、失败与排除原因见 `search.json`。

Belgrade 的概念 DOI 为 `10.5281/zenodo.4556923`。v1.0（4556924）的上表电压统计限于该版本。v1.1（5514279）和 v1.2（5514310）的公开 API 标记访问受限，未公开可读文件。最新 v2.0（5514351）单列 CC BY 4.0，包含七个正常运行时由 LC2 发至 LC1 的接收信号、一份新的 Table_2，以及与 v1.0 字节相同的 `T7_100.txt`。两个可读取版本按同一发布系列计数；各版本的数据来源和核验项目见 `sources.json`、`belgrade-version-audit.csv` 和 `version-notes.md`，复算入口为 `audit_belgrade_versions.py`。
