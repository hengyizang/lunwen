# 电机台架的命令、力矩与推力记录

本目录覆盖六组民用研究或教学台架材料。记录值保留源文件的符号、单位和采集层级。Stanford、Quanser、Aerostack2 与 Gestelt 的 CSV 同时给出 ESC 脉宽、力矩、推力和电流。Cao–Strawson 与 Bitcraze 的旧记录给出命令、推力和电流。全程未找到可将这些字段直接解释为同一轴端的限幅前请求、限幅后实际命令与独立力矩的证据。[检索记录](search.json)

| 来源 | 原始记录核验 |
|---|---|
| Cao、Strawson | 208 对原始和编辑后文件各含 11 个观测。原始推力没有相邻相等的采样，编辑版出现 82 对；这些点在 50 次试验中重复了同次原始峰值行的七个响应字段。电调命令继续上升。最大末点差为 67.3443 gf，发生在 j5_11.csv。作者 README 说明其绘图采用覆盖了回落点的数据。[逐文件核查](cao-strawson-edits.csv) |
| Stanford MSL | 两处目录保存同样的六个 Git 数据对象。6 次台架记录共 242 行，光学转速字段全零。电气转速、推力和力矩有变化。装有传感器与否需要从有效记录确认。[台架字段](bench-traces.csv) |
| Quanser | 一份记录的两轮上行阶梯各有 21 个点，每个脉宽恰好重复一次。两轮在相同命令下可对照力矩与有符号推力，结果还受供电条件影响。[同脉宽对照](repeated-pulse.csv) |
| Aerostack2 | 两份多旋翼带时间 CSV 的 1,245 行均可在 2,930 行六列输入表中匹配。单旋翼汇总表有 11,826 行，使用分号，作者默认逗号解析器会跳过它。135 行单旋翼斜坡中电气、光学转速字段均为零，力矩和推力仍有变化。[重合检验](map-input-overlap.csv) |
| Gestelt | 两组裁剪表都保留了母表的前缀。NUSwarm 被裁掉末行的光学转速值为 −1，Flywoo 的末行转速是正值。裁剪标记本身无法判定物理饱和。[文件对照](trimmed-rows.csv) |
| Bitcraze | 2015 表有 16 点，各步持续四秒。称重和万用表读数手工登记，同一期间记录了电压、PWM 和 RPM。表内一个 PWM 百分比是 43.25，偏离名义的 6.25 个百分点间隔。此表没有力矩测量。[表格核验](legacy-sweep.csv) |

复算使用 Node 20 及以上版本，命令为 `node recompute.mjs OUTPUT_DIRECTORY CACHE_DIRECTORY`。脚本逐个核对公开文件的 Git blob，输出六张 CSV。每个 `*-source.json` 给出固定版本、文件路径、使用许可和局限。
