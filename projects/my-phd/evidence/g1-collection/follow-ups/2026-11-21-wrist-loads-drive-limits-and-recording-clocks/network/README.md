# 两车通信、云端编队建议与实车运动记录

AUTOPILOT 的两处试验提供了互补的证据。Livorno 能逐条匹配两车之间的消息，还能在同一辆车的时钟上观察接收告警后的车速。Brainport 可以把同一份规划载荷追到服务、平台和车辆三个记录位置。两地都出现了接收日志早于对应发送日志的情况，因而要先验证时钟和记录位置，才能把时间差用于控制时延分析。

| 试验 | 文件测得的结果 |
|---|---|
| Livorno，10 次双车告警试验 | 两个方向共记录 19,109 次发送和 17,615 次接收。以同一试次、方向及全部 17 个 CAM 载荷字段为键，15,270 对在两端均唯一。另有 723 个共同键在至少一端重复。唯一匹配中有 930 对接收日志早于发送日志。[两车对照](livorno-cam-pairs.csv) |
| Livorno，告警与运动 | 对两辆车分别以本车首次接收 DENM 为零点。在 20 个车次中，有 18 个在零点和五秒处均有 ±150 ms 内的车速记录，这 18 个车次在五秒处的读数均降低。各车次首条告警的发送方检测时间字段均比本车接收日志晚约 3,171–3,173 秒。两车之间的 CAM 和自行车发起的 DENM 分属两种消息，减速的因果归属和控制器调用时刻仍待确认。[告警与速度](livorno-warning-and-speed.csv) |
| Brainport，5 次编队试验 | 完整 JSON 载荷在两车端各出现一次的蜂窝网车辆状态消息有 3,614 对，其中 2,233 对的接收日志早于发送日志。两次试验的两个方向甚至同时出现约 −0.9 s 的中位差。文献将该云端车辆信息通道与用于跟车的直接短距链路区分开来。[消息对照](brainport-message-pairs.csv) · [本车状态与速度](brainport-vehicle-status.csv) |
| Brainport，服务到车辆的规划建议 | 试验 193 中，发自服务日志、经平台日志到车端的完整载荷，在两条接收路径分别有 66 和 29 个唯一三方匹配。收发总时间差中位数分别为 40 ms 和 38 ms，中间节点时间早于服务记录的匹配分别有 61 和 24 个。试验 97 的 134 对服务与车端匹配中位差为 63.5 ms。[三处日志](brainport-three-logger-matches.csv) |
| 两组更早的 Livorno 试验 | 试次 177 有 24 条收到的 DENM，命名为 Vehicle 和 DriverVehicleInteraction 的两个文件各有 1,998 行，但列中只有行号、时间、记录器和应用标识。另一发布的六份车端记录缺少 CAM、DENM 收发动作标识，第七个压缩包仅含平台侧资料和描述文件。[按试次与字段的覆盖核验](livorno-related-channel-coverage.csv) |
| Aveiro，车辆、自行车及路侧传感器 | 六份 CSV 共 108,154 行。按文件原始顺序比较数据库插入时间，相机、雷达和激光雷达分别有 3,724、35、1 次回退。Luxonis 的 25,851 行插入时间均等于另一 timestamp 字段。发布说明称各流按时间戳排序，使用时应写明选择哪个字段。[时钟字段核验](aveiro-source-clocks.csv) |
| Gaia，移动客户端与路侧 Wi-Fi | 8 个试次、3 种无线制式合计 46,566 个“试次－制式－秒”观测。1,356 个观测出现监测到的接收字节数大于零、应用层接收吞吐量等于零。此文件汇总到秒，无法据此匹配单包收发。在 40x 试次，n/ac 信道占用率采用了作者的近似。[分试次接收统计](porto-v2i-receiver.csv) |

**复算**　使用 Python 3.11 或更高版本执行以下两条命令。脚本会从 Zenodo 获取指定版本并验证公开校验值。CSV 只含统计量，原始位置轨迹、文件和论文由源站提供。

```sh
python derive_autopilot.py /tmp/autopilot-cache /tmp/autopilot-results
python derive_channel_coverage.py /tmp/autopilot-cache /tmp/autopilot-results
```

CAM 的唯一匹配要求在同一试次和方向上，两端的非日志字段完全相同且各出现一次。未匹配的一端可能受记录窗口和缺项影响。Brainport 使用解析后的完整 JSON，忽略对象键顺序。试次 193 的服务端候选集合供两个目的地分别核对，两行发送数相加会重复计数。百分位按线性插值计算，负差保留。两项复算都在本轮实际执行。
