# 腕部静置漂移、跨姿态标定与装配接触

ATI 腕力传感器的静置记录与 ForceLDM 的装配示教提供了两类可核验的测量。前者适合检查零点稳定性和姿态之间的标定迁移，后者可用于检验接触标签与校准后六轴读数的关系。

| 观察 | 证据 |
|---|---|
| ATI 静置日志的 130,511 个样本覆盖 36.253 小时。末 600 个样本与最初 600 个样本相比，Fz 均值增加 0.635239 N，Mz 增加 0.001255 N·m。文件仅含时间与六轴读数，温度成因尚待测温记录验证。 | [逐时统计](gravity-static-windows.csv) |
| 用 7 个姿态拟合重力与偏置后，在同一文件上得到 0.004969 N·m 的力矩向量残差均方根。将同一组参数应用于另一份 100 姿态文件时，残差升至 0.203784 N·m。对这 100 姿态单独拟合，残差为 0.006096 N·m。两个文件间的工具配置和调零情况没有记录。 | [双向迁移与同文件对照](gravity-pose-transfer.csv) · [版本与字段](gravity-source.json) |
| ForceLDM 的 474 份示教文件共有 362,339 帧。在全部帧中，effort 字段的六维向量与机器人状态中的六个槽位数值完全相同。两者来自同一腕力测量。 | [逐文件行数及 SHA-256](forceldm-episodes.csv) |
| 以实测力的模长区分发布者保留的接触标签，齿轮装配 64,091 帧的 AUC 为 0.514111，擦板 70,810 帧的 AUC 为 0.987378。VGA 插接中有 203 个标签为零的示教帧超过 25 N。原文将 25 N 用于另一组评测试验的成功条件。 | [按任务与标签分组的统计](forceldm-tasks.csv) · [论文版本与解释边界](forceldm-source.json) |
| 原文表 7 的五项 xArm 任务共 332,237 帧，与数据文件精确相符。论文列出 420 次示教，公开版相应五项共有 423 个 episode 索引，并另含 51 段削皮示教。由现有记录无法解释索引与论文次数的差异。 | [数据版本与论文页码](forceldm-source.json) |

复算命令为 `python derive-gravity.py OUTPUT CACHE` 和 `python derive-forceldm.py OUTPUT CACHE`。前者使用 NumPy、SciPy，后者使用 NumPy、PyArrow。已核对两个上游版本的测量对象哈希，仓库保存自行生成的汇总表。两个数据仓库在所核版本均未声明数据再分发许可。
