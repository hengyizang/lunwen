## Spending and failure controls

The fixed cloud-state/model-comparison-20261020 branch stores an independent,
append-only attempt ledger. The authorization ID, plan and fixture hashes, exact
routes and call IDs are bound. A rerun does not reset the allowance or repeat an
attempt. Ordinary execute and reconcile leave stopped trials stopped; closed
trials never reopen. A separate owner-reviewed resume requires the exact stopped
ledger blob, its original authorization, and fully independently settled attempts.
It records review provenance and preserves all call IDs and the same limit.
Reservations count in
full until an independently attributable gateway debit is read.

Each fresh attempt reads the group's independent meter, calculates a conservative
reservation from the current exact price contract including cache writing, and
persists it with optimistic locking and readback before any generation request.
All calls are serial and share the production cloud concurrency group. A failed
response is still recorded and billed when the gateway provides an attributable
debit. Unknown charges stop all new paid work and retain their full reservation.
The explicit reconcile mode performs only free metadata reads and never reopens
or generates. The old allowance and production spending files are never written.

Actual observed debit, requested/reported model, requested effort, termination,
usage, duration, exact task hash and raw synthetic answer are preserved. Only
documented typed usage fields are saved. Credentials, gateway error bodies and
account details are excluded. Requested effort and echoed model labels are
traceability records, not independent attestations of real reasoning or weights.
