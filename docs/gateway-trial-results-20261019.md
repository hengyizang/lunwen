## 扣费、缓存与异常处理

费用采用用户指定规则：国外美元单价的数字按人民币计，国产官方价用人民币，再乘分组系数。网关余额实际扣费单独列示，不能把令牌估算当成真实扣费；这里的人民币数额按用户渠道结算规则折算，不等同于人民币银行账单。

每次生成前在独立持久账本预留费用。只有独立读取并唯一匹配网关扣费后才释放多余预留。CheapAI核对公开每余额单位500000额度和逐请求日志；CodeKey核对用量接口里恰好新增一次请求及实际扣费差。全部重启共用同一30元额度，付费请求编号不重复。

已修复缓存写入时效缺失、额外上下文、聚合计数与日志不同步，以及免费用量查询的限速处理。缺少时效就保留未知，不编造5分钟/1小时拆分；查询限速只重查免费接口。四道受查询限速影响且从未发送的第二题已补齐，生成请求没有因这些问题被重复发送。

CheapAI Kiro首条Sonnet回执计入12172个缓存读取和5970个缓存写入令牌，普通输入为0；额外上下文内容和来源未获验证。该条原始回答在早期解析路径中未完整保留，保留诊断缺失，不虚构答案、不重发。后续改为先保存脱敏回执再做计费检查。

CheapAI Claude 5.5的实际缓存读取比例为输入价10%，官方比例为5%；报价已按观察到的中转比例校正。Argon回执与网关扣费在本轮符合当前促销输入2、输出10的官方基价乘0.30，预算预留仍采用较高的非促销价。所有缓存与思考令牌仅计一次，没有付费保温或额外付费裁判。
