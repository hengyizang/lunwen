# v1.4 全链路审查结论

审查范围包括 UUAPI/CC Switch 接入、模型角色、G0–G5 状态机、原创性与博士论证、六篇论文边界、逐篇实验设计、实验执行、引用、英文投稿材料、图表、JCR Q1、人工审批和投稿包。

## 结论

代码层面已经覆盖并强制执行当前可机器化的要求；但代码、模型评分和模型一致意见都不能证明真实选题必然新颖、达到学位标准或被 JCR Q1 期刊录用。真实结论只能在项目生成 G1–G5 工件、完成最新文献/专利检索、运行真实实验并经人类逐门审批后形成。

| 要求 | v1.4 强制控制 | 仍需人确认 |
|---|---|---|
| Claude 不写最终文本/图表 | Claude 仅作只读计划和内部审查；Codex/OpenAI 写持久工件；长片段复制检测；最终文件必须有当前非 Claude 来源 | 人工证明不得为虚假证明；目视检查最终文件 |
| 新颖性/原创性 | 至少 5 项最近工作、3 个相邻领域、3 组查询、近期 cutoff、反证、非新颖部分、剩余风险、专利搜索状态 | 检索覆盖是否充分、来源是否真实、是否存在未索引工作 |
| 博士要求 | Theme A/Theme B、统一命题、知识贡献、跨论文综合、方法递进、范围与 examiner challenge；质量硬门槛 | 学校/导师/答辩委员会的正式认定 |
| 六篇论文独立性 | 默认 6 篇；完整两两比较（6 篇为 15 对）；唯一 claim ID；合并触发条件和反切香肠检查 | 论文组合是否适合具体博士制度 |
| JCR Q1 实验设计 | 每篇独立设计；当前强基线、领域/简单基线、公平调参、消融、泄漏、效应量/区间、多重性、功效/精度、至少 3 随机种子、稳健性、负对照、外部有效性、证伪 | 领域审稿人对方法价值和数据充分性的判断 |
| 实验真实性 | G3 批准计划/预算哈希锁；无 shell 执行；每次尝试登记；G4 校验种子、命令、论文、输入/输出及当前哈希 | 代码本身是否正确、仪器/数据生成过程是否可信 |
| Claim 校准 | claim matrix 必须精确覆盖 contract；支持性 claim 至少引用一次成功运行；失败/超时保留 | 对效果的科学解释和因果边界 |
| 英文正文与投稿文本 | 主稿、补充材料、表格和投稿目录文本自动语言检查；DOCX 引用需具名人工核对 | 学术英语质量、语气和领域写作习惯 |
| 最终图表 | 本地确定性渲染；输入、运行、渲染器、配置、输出哈希；渲染器/配置非 Claude；具名英文标签检查 | PNG/PDF 的最终视觉质量和全部标签 |
| JCR Q1 | 候选和最终目标仅接受当前/上一版 JCR Q1 SCI/SCIE；最终记录需近期人工核验 | 使用机构 Clarivate 权限确认类别、年度、范围和政策 |
| 审查与审批 | 初审/终审严格 schema；fatal/major/missing/remediation/unresolved 均关闭闸门；`ready` 快照锁；模型不能批准 | 每一道 `approve` 必须由真实研究者作出 |
| 投稿 | 仅生成本地 ZIP；内部审稿和控制文件不进入上传包；G5 后改动会阻止打包 | 登录、选择上传槽、预览并手动提交 |

## 推荐使用路径

1. 在 WSL2 中配置 UUAPI 四个环境变量，并运行非计费 health、余额和两个最小 live probe。
2. 第一次可执行：

   ```bash
   bash scripts/start.sh my-phd '完整填写背景、技能、目标、时间、预算、设备、数据和伦理约束'
   ```

3. 每次模型循环后只先检查：

   ```bash
   python3 scripts/researchctl.py status --project my-phd --json
   python3 scripts/researchctl.py gate-check --project my-phd
   ```

4. 只有内容正确且 `gate-check` 通过时，依次运行 `ready`、人工 `approve` 和 `advance`。`ready` 后若需要模型修改，先用 `researchctl.py reopen --note '原因'` 退回；修改后必须重新检查并再次 `ready`。
5. G3 批准后才可运行 `experiment_runner.py`；G4 前补齐 claim matrix；G5 前重新运行引用、英文、图表、期刊和 JCR 检查。
6. 每篇 G5 通过并推进后，才运行 `submission_package.py`；ZIP 仍由人手动上传。

完整命令见 `README.md`、`docs/API-FIRST.md` 和 `docs/UUAPI-CC-SWITCH.md`。
