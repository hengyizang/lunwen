# 细分任务与模型复评：2026-10-29

`config/task-model-policy.json` 登记 48 个任务类别、风险下限、既有执行入口和质量要求。
`scripts/route_review.py` 将当前任务与已有调用、可用性、健康检查、费用和接纳记录一起审查。
它只返回管理状态，不调用模型、不写研究状态、不授予消费或科学关卡权限。

本次 Argon、DeepSeek、Terra、Kimi 的连通性和短任务结果应记录为对应精确渠道、型号、档位、
输入范围和日期的观察。一次响应不能证明型号权重、新颖性或与基线等质。只有满足项目原有
成对任务、留出材料、独立人工判断和实际费用要求的候选，才可作为该任务的生产替代。
模型可用性、任务表现、科学判断资格和预算授权分开记录。

候选登记补入 CodeKey Terra high/medium、Kimi high 和 Argon high 的兼容文本接口，
均保持 `candidate`。它们的 64 KB/8192 token/300 秒是候选请求上限，不能冒充已验收范围；
实际选择还受同类任务验收中更小的输入输出范围约束。Terra 只有通过既有正式验收后才可能
替代常规 OpenAI 写入任务；核心科学模型、家族和档位下限继续保持。Kimi 不获得持久科学
文件写入或 Claude 科学终审权限。Kimi 密钥已接到现有科研、续跑和免费准备检查工作流。
新增报价用于保守预留，Kimi 在中转费率核实前按官方人民币 1x 上界；实际费用仍逐笔核对，
缓存读写都计入预算。短测不会自动生成正式接纳记录或启动科研。

把新型号放进待验证池；不能根据商家的“满血”“最新”或一次自报型号直接晋升。

## 正常情况下怎样及时评估

1. 每次现有请求前声明真实细分任务，按登记应用风险下限；未分类的后期科学工作继续保守处理。
2. 读取当前调用、缓存、身份、完整性、费用与接纳证据。程序足够时直接使用程序。
3. 生产 POST 前继续使用原有免费精确型号目录检查及独立计费预检。目录缺失是“可用性未知”，
   目录列出型号也不能证明底层权重、推理档位或质量。
4. 近 24 小时没有该精确路由的实际调用时标记运营复查；接纳记录超过 7 天时标记证据复查。
   这些是复查提示，不自动发起付费探针，也不把已过期观察冒充当前测量。
5. 最近调用的时延或单次费用明显上升时提示复查。当前阈值为时延 1.5 倍、费用 1.25 倍；
   输入长度、输出长度和缓存变化也能触发，因此它们不是直接替换模型的质量/价格结论。
6. 精确价格契约变化、型号/版本变化、任务转为核心科学、输入输出超出已有验收范围或出现质量问题，
   都应重评对应任务。候选的实际净成本包括错误、返工、缓存读写和失败请求。

`route_review.review` 可接收刚取得的 `catalogs: {provider: [exact_model_id]}` 和
`quote_hashes: {"provider/model/effort": "当前SHA256"}`。没有传入的观察保持 unknown。
报告绑定原有来源文件，输出经过裁剪的事件和状态，不输出密钥、请求正文、账户余额或原始账单。
状态报告本身不能选择或接纳替代；现有 `dynamic_routing` 继续重查全部接纳、角色、价格和预算条件。

## 突发情况怎样处理

| 事件 | 当下动作 | 可以换模型的条件 |
| --- | --- | --- |
| 免费目录检查已确认型号不可用，尚未发送生成请求 | 记录 `generation_sent:false`，重新检查任务与可用候选 | 只能使用该任务已接纳、当前可用、保持角色/家族/档位/完整输入的替代 |
| 请求超时、断连、取消或响应不完整 | 保留实际尝试与输出，先核对是否计费 | 未核清费用时阻断；核清后仅在单独有界的重试授权下继续，不自动 POST 到别家 |
| 请求/返回型号不符或模型身份不足 | 隔离该精确路由，不接纳其正文或质量分数 | 先修复/核对身份契约；不把相似别名直接当真型号 |
| 发现伪造引用、错误数值、来源契约失败或科学质量回落 | 暂停受影响路由，记录具体缺陷与证据 | 用实际同类任务复查，不能只通过一次“OK”探针恢复科学资格 |
| 价格、缓存费或计费计数器变化 | 保留旧账单和待核费用，更新精确报价与范围 | 新契约和实际成本证据核对后再评估，不能用估算替代实扣 |
| 当前任务变为核心创新、统计解释或复杂返修 | 提升任务风险，恢复相应科学下限 | 不允许为省钱把核心任务声明为常规任务 |
| 新型号发布或渠道改名 | 免费核对官方发布与精确目录，记录候选 | 单独的短任务测试只说明局部表现；生产晋升仍需原有任务验收 |

中央 500 元预算、旧费用保留和未知新费用暂停继续有效。任何本轮特定测试例外只适用于
该批次的明确范围，不能使正式科研流程绕过未知费用、人工 G0–G5 或批准的 G3 执行。
