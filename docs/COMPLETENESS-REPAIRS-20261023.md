# Completeness repair acceptance map

This update closes the eleven engineering findings in the 2026-10-23 completeness audit. Acceptance is the cloud checks for the exact PR commit, including the dedicated completeness regression, the full Python-version matrix, literature acceptance and all-seventeen CCFA acceptance. The tests use synthetic inputs and no paid model credentials. Their results establish software behavior, not research validity or publication merit.

| Finding | Implemented boundary | Primary cloud regression |
| --- | --- | --- |
| A01 Current independent review | Protected initial/final phase receipts bind scientific source hashes, stage, paper, actual model identity and author dispositions. G5 and packaging recheck H01–H26, AD01–AD08 and CFH01–CFH38. | `test_review_receipts`, `test_submission_package` |
| A02 Critic independence | Actual API/CLI packets exclude raw request envelopes, echoed operational reports and preferred verdicts. Explicit context-plan selections receive the same boundary; CLI critics cannot reread excluded files through tools. | `test_review_receipts`, `test_cli_invocation_controls`, `test_api_first` |
| A03 One doctoral topic | Human G1/G2 seals protect the doctoral question, core/extension relationship, paper mapping and independent contributions. A source-bound owner amendment reopens the affected gate for fresh scientific review and approval. | `test_scientific_scope` |
| A04 Primary failure recovery | An exact owner approval permits the next unchanged infrastructure retry. Protocol retirement preserves inputs, partial outputs, successful outputs and failed receipts, requires increasing versions and returns to G3 with new run/output IDs. All retired compute remains chargeable, including later supplemental experiments. | `test_primary_recovery`, `test_experiment_evidence`, `test_study_routes` |
| A05 Figure lineage | Inputs must match exact executor run, attempt, plan, protocol and output seals. Confirmed supplemental child runs and deterministic, replay-verifiable derived CSV data are supported. The writer can request `derive_figure_data` before native rendering. | `test_figure_lineage`, `test_figure_provenance` |
| A06 Shared credential charges | Test/production jobs share a CAS lease by credential fingerprint, import historical unresolved charges, bind one POST and exact debit evidence, and keep unknown fees locked. Reconciliation checks retained source rows; rotation preserves the old credential hold. | `test_relay_guard`, `test_production_runtime` |
| A07 Literature evidence | Citation chaining must come from the executed citation-graph mode, source DOI and direction with original/normalized edge evidence. Consecutive saturation rounds require distinct executed search receipts. | `test_research_quality` |
| A08 Complete manuscript sources | Ordered TeX expansion preserves original locations; writing/citation/language audits see included chapters. Submission dependencies include source, bibliography, licensed local styles and figures, with traversal/cycle/privacy guards. | `test_tex_sources`, including extracted-ZIP compilation after removing the source project |
| A09 Applicable skill references | Ordinary API/CLI task prompts receive the complete applicable pinned references for the task/mode, including the universal Humanization policies. | `test_ccfa_reference_routing`, `test_ccfa_model_handoffs` |
| A10 Safe resumption | An unchanged successful science operation reuses its source- and implementation-bound report without rewriting history. Changed requests or stale sources still require the exact current CAS. | `test_ccfa_science` |
| A11 Duplicate context | Default stage guidance, active specialists and explicit references are assembled once per pinned source hash while retaining applicable instructions and fresh independent review calls. | `test_ccfa_reference_routing`, `test_ccfa_runtime` |

Owner recovery and spending operations are documented in [Primary recovery and shared relay guard](PRIMARY-RECOVERY-AND-SHARED-RELAY-GUARD.md). Scope changes and current critic receipts are documented in [Scientific scope and reviews](SCIENTIFIC-SCOPE-AND-REVIEWS.md). Figure derivations and source packaging are documented in [Figure lineage and TeX sources](FIGURE-LINEAGE-AND-TEX-SOURCES.md).

Actual topic selection, authorized datasets, original study execution, scientific judgment, journal fit and human approvals still require real project evidence. Model allocation and reasoning settings are outside this repair. Historical unknown charges remain subject to reconciliation; a metadata check cannot declare the affected credential ready for paid use.
