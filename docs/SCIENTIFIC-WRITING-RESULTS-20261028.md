## 匿名辅助审读观察

先提供来源、任务与匿名候选文本，完成审读后才对应型号。以下为 Codex 模型辅助
检查，不是独立人工盲评，没有虚构评分者、分数或模型晋升记录。每题主要依据
给定原文摘录核验，不能替代阅读全文和学科专家判断。

| 独立来源与任务 | 具体观察 |
| --- | --- |
| seaborn，引言 | 只有Sol一份有效候选；问题—接口机制—底层定制的主线清楚。同一来源反复双重引用略机械，“obscure the correspondence…”属于额外动机解释，可删除或减弱。不能形成模型间比较。 |
| Pingouin，方法描述 | Astra局部措辞略克制。Sol的“rather than requiring a separate data representation”超出原文对流程整合的描述；Astra的“reproducible…workflows”也超出原文仅提供notebook示例的证据。两份均应压缩重复功能清单。 |
| corner，摘要 | 接近持平，Astra的“can reveal covariances”表达较审慎；其“wherever”又比原文“many qualitatively different samples”更宽。Sol的边缘/成对投影概括合理。 |
| ArviZ，讨论 | Sol的论证衔接略自然；Astra“allows inference to remain associated…”较空泛。两份末尾都有不必要的写作过程说明，应回到实际支持的贡献。 |
| emcee，能力/结果描述 | 两份均保留内存默认存储、HDFBackend、moves接口及性能适用条件。Sol较凝练；Astra以整段重复否定普遍性能优势，分散主线。“HDF5-backed”是摘录之外的合理技术引申，应区分于原文直接支持。 |
| scikit-posthocs，改稿 | 两份都清除了虚构的普遍显著性、两倍性能和热图证明假设等错误。Astra明确“At the time of publication”，历史范围更准确；Sol直接写支持Python2/3，需要补2019年出版语境。两份检验名称均可精简。 |

在这些有效候选中，辅助审读没有发现明确捏造实验数值、虚构引文或因果夸大。
仍发现可定位的证据外扩写、历史范围歧义、冗余和防御性结尾，需要逐项修订。
这不是完整科学正确性认证，更不是“所有输出可以不经检查直接使用”。

不同题目各有细微优势，样本和评价方式均不足以支持全面模型排名。特别是多数
源文为短篇历史软件论文，缺乏真实数值结果与长文跨章节依赖；没有验证完整结果段、
博士创新、论文整体质量、AI检测分数或Q1录用概率。独立人工盲评仍待完成。

## 对当前项目的决定

保留Sol high处理常规局部写作、Astra high处理核心科学论证的现有路线。
本轮没有证据支持为所有普通段落都增加一次Astra重写，也没有依据把Argon提升为
正式作者。来源、数字、引文和结论范围检查继续保留。

写作提示还应避免将内部核验禁令机械地复制为正文中的否定性结尾：必要条件必须
说明，重复的写作过程声明应留在内部审查记录。此观察没有改写本轮冻结提示或
重复付费采样，也没有移除必要的不确定性。

继续评估Argon前，需要中转站提供符合约定的可核验模型标识或修复接口。
两个已付费请求及全部旧预留保留；没有自动尝试第三种接口或替代模型。
