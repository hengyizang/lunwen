# Task guidance and historical stage names

These sections preserve familiar G0–G5 names for existing commands. Select the task that helps the current research question; no section is a mandatory predecessor or a full-form completion requirement. Use [AGENTS.md](../AGENTS.md) and [workflow.md](workflow.md) for current operating policy.

## Intake — G0

Record the user's question, existing materials and known resource limits. Reuse information from the conversation. Do not delay a useful read, calculation or draft to fill irrelevant intake fields. Unknown budget is not permission to spend.

## Topic intelligence — G1

Read the most relevant primary work and plausible counterevidence. Distinguish a consequential problem from a new contribution: each needs its own reasoning. Compare alternatives when the choice depends on them; there is no universal minimum count of candidates, papers or query rounds. Search absence alone does not demonstrate novelty. Save actual sources, read scope, search limits and the next question worth resolving.

Career or funded-position ranking is a separate optional task using the user's actual criteria, not a prerequisite for research. Provisional topic choices can evolve with evidence; preserve material changes and do not invent user decisions.

## Paper architecture — G2

Organize a paper around a coherent question, knowledge increment, evidence and reader value. Add a paper only when it has standalone value; combine redundant contributions. Existing six-paper or A/B plans remain usable project history, not a universal template. Reuse data or code openly and explain distinct claims where it matters.

## Experiment design — G3

Choose a design appropriate to the claim. Check independent units, estimand, data suitability, leakage, comparison fairness, uncertainty and relevant alternatives. Use power, precision, robustness, negative controls, multiple-testing treatment or replication where their scientific purpose warrants them. There is no blanket seed count, two-replay rule or fixed baseline suite.

For confirmatory work, fix important hypotheses, exclusions, outcomes and analysis choices before observing the outcome. Record later deviations and prior exposure. Bounded exploration can start with incomplete knowledge and supports appropriately qualified findings; it need not impersonate confirmation. Mathematical proof, Meta-analysis and qualitative inquiry use their own positive evidence rather than fabricated empirical fields.

Plan an actual executable action with sources, expected outputs and available resources. Choose an appropriate environment, including the existing experiment runner when useful. A native engine's unsupported method is a capability limitation, not a scientific prohibition.

## Experiment execution — G4

Run the actual method. Keep inputs, relevant environment/code versions, commands, outputs, failed attempts and costs. Preserve originals when repairing a technical failure; avoid replaying successful work unnecessarily. Apply the same stated scientific criteria to favorable, null, adverse and inconclusive results.

Interpret estimates with their uncertainty and assumptions. Seeds are not automatically independent subjects; a small p-value is not importance, and nonsignificance is not equivalence. Label causal, mechanistic and external-validity inferences only as far as the design supports them. Recorded execution does not itself validate the inference.

## Writing and review — G5

Write during research, clearly distinguishing prior evidence, plans, observations and interpretation. Center the strongest supported contribution and the evidence that changes the reader's understanding. Material claims and presented numbers need traceable support; a required paragraph-by-paragraph ledger is unnecessary. Preserve interpretation-changing contrary evidence; keep complete logs separately.

Use scientific review to resolve real uncertainty. Reviewers need the relevant original sources and enough context; preserve disagreement rather than taking model votes or scores as truth. A fixed three-family panel, human claim-label quota or complete editorial scorecard is optional methodology, not general clearance.

For the actual intended deliverable, inspect citation identity and support, numbers, figures, rendering and applicable publisher requirements. Rank and impact factor do not determine scientific validity. Preserve real author/ethics/funding facts and truthful assistance records. A local package is preparation, not submission; follow actual authorization for external release.

## Historical records

Keep previous state, approvals, protocols, reviews and outputs readable. Do not rewrite old bytes to match new defaults, fabricate confirmations or claim that engineering fixtures demonstrate completed research. Compatibility validators may describe old missing fields; they do not determine the next useful action in the research-first path.
