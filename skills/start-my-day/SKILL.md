# Start My Day

Use current research questions and existing notes to find genuinely new direct, adjacent or contrary sources. Avoid repeated full-text processing of unchanged papers. Prepare a short reading/action list with actual sources and unresolved questions; discovery signals do not establish scientific conclusions. Create a scheduled job only if requested, and do not require a six-paper structure.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
