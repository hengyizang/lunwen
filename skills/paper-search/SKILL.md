# Paper Search

Start with existing sources, then search relevant direct, adjacent and contrary terms using available services. Preserve useful query/date/source details and distinguish retrieved, deduplicated and read counts. Use `scripts/literaturectl.py` or native literature APIs where appropriate. Keyword nonmatches and empty exact queries do not prove absence or novelty. Refine queries within existing task authority without another owner approval.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
