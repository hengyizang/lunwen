# Topic

Read relevant primary work and counterevidence, distinguish importance from novelty, and identify a feasible informative test. Compare serious alternatives only as needed; no fixed three-direction, second-doctorate or six-paper plan is required. Career/funding comparison is optional when requested. Preserve source scope and unknowns, make a concrete recommendation and continue evidence gathering within user authority. Do not invent the user's choice.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
