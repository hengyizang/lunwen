# Data

Use official sources or supplied data and preserve versions, raw observations and relevant transformations. Check analysis units, missingness, duplicates, split leakage and task fitness. `scripts/data_discovery.py` returns leads; `scripts/dataset_fetch.py` can fetch an actual selected manifest. Respect known access and privacy restrictions, but do not add a licence-signature gate or assume metadata proves permission. Choose methods appropriate to the study; see `references/research-methods/empirical-data.md`.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
