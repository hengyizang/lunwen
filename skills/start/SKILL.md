# Start

Use `python3 -m scripts.researchctl init --project <slug> --question "research question"` for a new project; do not overwrite an existing one. Record the next task with `researchctl work` and proceed directly with available tools. `python3 -m scripts.autopilot start --project <slug> --context "next useful action"` uses configured model execution within existing authority. New projects default to one paper and no authorized spend. Ask only about a consequential missing input, while continuing independent work; no complete intake or stage dossier is required.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
