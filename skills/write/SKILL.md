# Write

Write alongside research using any capable model. Distinguish prior work, planned analyses, observed findings and interpretation; clearly mark missing results. Lead with the important problem, strongest supported contribution, decisive evidence and bounded value. Preserve interpretation-changing negative/uncertain outcomes and keep complete logs separately.

Read `references/research-methods/evidence-arguments.md`. Verify important citations and presented numbers against the appropriate original evidence. A paragraph plan, paper-facts table, reporting checklist or review panel is useful only when it helps the task or actual target. No G4 approval, vendor restriction or full source-unit ledger is required to draft.

Render data figures from actual values and inspect the manuscript output. Choose language and format for the intended readers; use TeX, DOCX or another suitable editable source without competing canonical versions. Correct real findings; do not add repeated disclaimers or substitute detector scores for scientific judgment. Keep actual author/ethics/funding/assistance facts truthful and follow user authority for external release.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
