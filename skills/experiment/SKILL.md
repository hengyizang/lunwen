# Experiment

Identify the consequential unknown and the smallest useful test. Select appropriate comparisons, analysis units, uncertainty and resources; use a pilot only when it reduces a real execution uncertainty. Set confirmatory choices before observing outcomes and label exploration honestly. Use `scripts/experiment_runner.py` or another suitable available tool within user authority and budget. Record actual inputs, outputs, failures and cost. Do not require fixed seeds, all imaginable controls, G3/G4 human approval or a complete future paper before working.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
