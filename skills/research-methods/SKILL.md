# Reviewed research methods

Use scripts/research_methods.py --stage <stage> --role writer to load the
installed, stage-scoped method modules. Read config/research-methods.json for
the source pins, routes and deeper references.

At topic-intelligence, read references/research-methods/topic-hypotheses.md and
references/research-methods/paper-cards.md. Write the concrete hypothesis input
after direction screening. Run scripts/research_candidates.py hypotheses
with the program/hypothesis-register.json input and program/hypothesis-audit.json
output. Paper cards are optional reading aids and never independent evidence.

At design/execution/writing, read
references/research-methods/evidence-arguments.md. Reuse the established fact,
claim, experiment and revision ledgers.

At writing-and-review, read references/research-methods/submission-review.md.
Write the criterion-bound checklist and run scripts/pre_submission_review.py.
Keep reviewers independent and all persistent scientific wording non-Claude.
Enforce the existing cumulative project totals without tranches or per-call or
per-paper caps. Only G1 doctoral-topic and G2 paper-topic decisions are human;
other stages use evidence-bound automated checks without invented signatures.

Execute helpers on the selected cloud runner. Do not install a runtime on the
researcher's computer or invoke paid services just to use these methods.
