# Local research library

Ask the user for the exact D-drive/WSL folder and their authorization to read it. Run `scripts/local_library.py --project <slug> --source '<folder>' --actor '<person>'`. The script indexes metadata/hashes and creates a local research-wiki index; it does not upload, copy or publish original files. Check any malformed entries, license limits and source locations manually. Use PaperQA2 only on authorized local full text and keep its output advisory; DOI and content assertions require source-level validation.
