# Library Import

Use the already authorized local Zotero export, Obsidian notes or PDFs. Inspect the source scope, retain originals and build the relevant local index using existing library tools. Do not require D-drive paths or re-ask for access already granted. Preserve actual metadata and privacy; indexing is not proof of full-text reading.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
