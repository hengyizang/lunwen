# Package

Use `python3 -m scripts.submission_package --project <slug> --paper <paper>` for the native package or an appropriate target-specific export. Check actual manuscript sources, figures, references and rendered files; retain a usable manifest and exclude secrets/private raw data. Package content is independent of model brand or old stage status. Do not require an unrelated review scorecard. A ZIP is preparation, not a submitted manuscript; external upload follows actual user authority.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
