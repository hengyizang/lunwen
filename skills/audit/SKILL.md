# Audit

Start from the actual question or suspected error. Inspect the relevant original sources, data, analyses and rendered material; report what is supported, contradicted or still unknown. Use citation, result and revision tools where they answer that question. Do not turn style scores, missing optional forms, fixed panel counts or old G0–G5 checks into new blockers. See `references/research-methods/submission-review.md`.

Follow the current research-first principles in `AGENTS.md`; use this capability whenever it helps the task. Historical stage labels are compatibility context, not prerequisites.
